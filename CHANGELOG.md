# Changelog

All notable changes to Fixit Pro will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.4.0] - 2026-09-24

### Added
- ✨ **AI Quick Fix** — Single-error fixes powered by GitHub Copilot.
- 🚀 **Batch Fix All** — Fix all errors in a file with one command (Pro feature).
- 💎 **Pro License System** — RSA-2048 cryptographic license validation.
- 🌍 **Dual Payment Options** — Razorpay (India, ₹499) and Dodo Payments (International, $15).

### Changed
- Replaced insecure HMAC license keys with RSA-2048 public/private key signatures.
- Improved paywall dialog with clear pricing for each region.
- Added license key input validation.

## [1.2.0] - 2026-05-15

### Added
- Initial release of inline diagnostics.
- Configurable colors, font size, and message length.
- Toggle command and severity filters.

## [1.0.0] - 2026-03-01

### Added
- First public release on VS Code Marketplace.
