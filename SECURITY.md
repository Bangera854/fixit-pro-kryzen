# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 1.4.x   | ✅        |
| 1.3.x   | ⚠️ (Critical fixes only) |
| < 1.3   | ❌        |

## Reporting a Vulnerability

If you discover a security vulnerability in Fixit Pro, please **DO NOT** open a public issue.

Instead, please email **sandharshbangera@gmail.com** with:
- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Any suggested fixes

You will receive a response within 48 hours. Please give us reasonable time to address the issue before publicly disclosing it.

## Known Security Measures

- License keys are validated using RSA-2048 public-key cryptography.
- No telemetry or personal data is collected by the extension.
- All AI requests are handled through the user's own GitHub Copilot subscription.
