# Contributing to Fixit Pro

First off, thank you for considering contributing to Fixit Pro! 🎉

## Code of Conduct

Be respectful, inclusive, and constructive. We're all here to build something great.

## How Can I Contribute?

### 🐛 Reporting Bugs
- Check existing issues first to avoid duplicates.
- Use the [Bug Report template](.github/ISSUE_TEMPLATE/bug_report.md).
- Include your VS Code version, OS, and steps to reproduce.

### 💡 Suggesting Features
- Open a [Feature Request](.github/ISSUE_TEMPLATE/feature_request.md).
- Explain the problem the feature solves, not just the feature itself.

### 🔧 Pull Requests

1. Fork the repository.
2. Clone your fork:
   ```bash
   git clone https://github.com/YOUR_USERNAME/fixit-pro.git
   cd fixit-pro
